
# Changelog

All notable changes to Easy Calculator are documented in this file.

## [2.0] - 2026-11-19

### Added
- Scientific Mode.
- Trigonometric functions: sin, cos, tan.
- Inverse trigonometric functions: asin, acos, atan.
- Square root and power operations.
- Factorial calculations.
- Natural logarithm (ln) and base-10 logarithm (log10).
- Exponential function.
- Mathematical constants: π and e.
- DEG/RAD angle mode switching.

### Changed
- Redesigned the application interface.
- Improved the dark theme.
- Updated calculator button layout.
- Improved expression parsing and calculation engine.

## [1.0] - Initial Release

### Added
- Basic calculator functionality.
- Standard arithmetic operations.
- Initial application interface.
- Calculation history.
