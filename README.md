# Easy Calculator

A simple desktop calculator built with Python and CustomTkinter.

## Features

- Addition, subtraction, multiplication and division
- Parentheses and decimal numbers
- Percentage and sign-change buttons
- Keyboard input, Enter to calculate, Escape to clear
- Dark interface
- Safe arithmetic parser (does not use `eval()`)

## Requirements

- Python 3.10 or newer
- Windows, macOS or Linux with Tk support

## Installation

```bash
python -m pip install -r requirements.txt
```

## Run

```bash
python main.py
```
