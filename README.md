# Easy Calculator

A modern desktop calculator for Windows featuring Standard and Scientific modes.

**Current Version: 2.0.0**

Easy Calculator is a desktop application built with Python and PySide6.
It provides an intuitive interface for everyday calculations and advanced
mathematical operations.

## Features

### Standard Mode
- Addition, subtraction, multiplication and division.
- Mathematical expressions.
- Calculation history.

### Scientific Mode
- Trigonometric functions: sin, cos, tan.
- Inverse trigonometric functions: asin, acos, atan.
- Exponentiation.
- Square root.
- Factorial.
- Natural logarithm (ln).
- Common logarithm (log10).
- Exponential function (exp).
- Mathematical constants π and e.
- DEG/RAD angle mode switching.

### User Interface
- Modern dark theme.
- Built with PySide6.
- Easy switching between calculator modes.
